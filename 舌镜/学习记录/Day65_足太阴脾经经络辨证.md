## 一、经脉循行

### （一）经脉主干

**《灵枢·经脉》原文：**
> 脾足太阴之脉，起于大指之端，循指内侧白肉际，过核骨后，上内踝前廉，上腨内，循胫骨后，交出厥阴之前，上膝股内前廉，入腹，属脾，络胃，上膈，挟咽，连舌本，散舌下。其支者，复从胃，别上膈，注心中。

**现代解剖路径：**

| 节段 | 循行路径 | 关键体表标志 |
|------|----------|--------------|
| 起始 | 足大趾内侧端（隐白） | 趾甲根角内侧0.1寸 |
| 足部 | 沿赤白肉际上行 | 经第一跖趾关节（核骨）后 |
| 踝部 | 内踝前缘上行 | 过内踝前下方凹陷 |
| 小腿 | 沿胫骨后缘上行 | 于内踝上8寸处交出厥阴（肝经）之前 |
| 膝股 | 沿膝内侧、大腿内侧前缘上行 | 经阴股前廉 |
| 腹部 | 入腹，属脾，络胃 | 距前正中线4寸（腹哀、大横等） |
| 胸部 | 上膈，挟咽，连舌本，散舌下 | 距前正中线6寸（周荣、大包等） |
| 支脉 | 从胃上膈，注心中 | 与手少阴心经相接 |

### （二）络脉

**《灵枢·经脉》：**
> 足太阴之别，名曰公孙。去本节之后一寸，别走阳明；其别者，入络肠胃。

| 项目 | 内容 |
|------|------|
| 络脉名称 | 公孙（络穴） |
| 位置 | 第一跖骨基底部前下方，赤白肉际 |
| 走向 | 别走足阳明胃经 |
| 分支 | 入腹，络肠胃 |
| 主治 | 脾胃病、肠腑病 |

**络脉病候：**
- 实证：肠中切痛（肠绞痛）
- 虚证：鼓胀（腹胀如鼓）
- 取穴：公孙

### （三）经筋

**《灵枢·经筋》：**
> 足太阴之筋，起于大指之端内侧，上结于内踝。其直者，结于膝内辅骨，上循阴股，结于髀，聚于阴器。上腹，结于脐，循腹里，结于肋，散于胸中。其内者，著于脊。

| 分布层次 | 具体位置 | 主治 |
|----------|----------|------|
| 足部 | 大趾内侧→内踝 | 足大趾内踝痛 |
| 膝部 | 膝内辅骨（胫骨内侧髁） | 膝内侧痛 |
| 股部 | 阴股→髀→阴器 | 大腿内侧痛、阴器抽痛 |
| 腹部 | 脐→腹里→肋→胸中 | 腹中急痛、胁痛 |
| 脊部 | 内行者著于脊 | 脊内痛 |

**经筋病候：** 足大指支，内踝痛，转筋，膝内辅骨痛，阴股引髀而痛，阴器纽痛，上引脐与两胁痛，膺中脊内痛。


## 二、重点穴位功效

### 1. 隐白（井穴·木）⚠️

| 项目 | 内容 |
|------|------|
| 定位 | 足大趾内侧，趾甲根角侧后方0.1寸 |
| 属性 | 井穴，五行属木 |
| 核心功效 | ①健脾统血（崩漏要穴）②调经止带 ③醒神开窍 ④益气摄血 |
| 主治 | 崩漏、月经过多、便血、尿血、癫狂、多梦、惊风、腹胀 |
| 操作 | 浅刺0.1寸；**灸法尤宜**（艾炷灸3-5壮，艾条灸5-10分钟） |

**⚠️ 孕妇禁忌：** 孕期禁用强刺激，灸法慎用。

### 2. 太白（输穴·土·原穴）

| 项目 | 内容 |
|------|------|
| 定位 | 第一跖骨小头后下方赤白肉际凹陷处 |
| 属性 | 输穴，五行属土，脾经原穴 |
| 核心功效 | ①健脾化湿 ②理气和胃 ③扶脾土、助运化 |
| 主治 | 胃痛、腹胀、腹痛、泄泻、痢疾、便秘、体重节痛、脚气 |
| 操作 | 直刺0.5-0.8寸，可灸 |

### 3. 公孙（络穴·八脉交会穴·通冲脉）

| 项目 | 内容 |
|------|------|
| 定位 | 第一跖骨基底部前下方，赤白肉际 |
| 属性 | 络穴，八脉交会穴（通冲脉） |
| 核心功效 | ①健脾胃、调冲任 ②理气止痛 ③消食化积 |
| 主治 | 胃痛、呕吐、腹痛、泄泻、痢疾、心烦、失眠、逆气里急、奔豚气 |
| 配伍特色 | 配内关（心包经络穴）——主治胃、心、胸疾病（八脉交会配穴法） |
| 操作 | 直刺0.6-1.2寸，可灸 |

### 4. 三阴交（足三阴经交会穴）⚠️

| 项目 | 内容 |
|------|------|
| 定位 | 内踝尖上3寸，胫骨内侧缘后方 |
| 属性 | 足太阴、少阴、厥阴经交会穴 |
| 核心功效 | ①健脾利湿 ②调和肝肾 ③调经止带 ④安神定志 |
| 主治 | 肠鸣腹胀、泄泻、月经不调、痛经、崩漏、带下、遗精、阳痿、遗尿、失眠、下肢痿痹 |
| 操作 | 直刺1-1.5寸，可灸 |

**⚠️ 孕妇禁忌（P0）：** **禁针**——有引发流产风险，为刺灸禁忌第一等级。

### 5. 阴陵泉（合穴·水）

| 项目 | 内容 |
|------|------|
| 定位 | 胫骨内侧髁下方凹陷处 |
| 属性 | 合穴，五行属水 |
| 核心功效 | ①健脾利水（利水第一要穴）②通利下焦 ③祛湿消肿 |
| 主治 | 腹胀、泄泻、水肿、黄疸、小便不利、遗尿、膝痛 |
| 配伍特色 | 配水分、足三里——利水消肿；配三阴交——健脾渗湿 |
| 操作 | 直刺1-2寸，可灸 |

### 6. 血海

| 项目 | 内容 |
|------|------|
| 定位 | 髌骨内上缘上2寸，股四头肌内侧头隆起处 |
| 命名含义 | 血之海洋——脾经所生之血聚集处 |
| 核心功效 | ①活血化瘀 ②调经统血 ③祛风止痒 ④清血热 |
| 主治 | 月经不调、痛经、经闭、崩漏、瘾疹、湿疹、皮肤瘙痒、膝股内侧痛 |
| 操作 | 直刺1-1.5寸，可灸 |


## 三、辨证分型

### 证型一：脾气虚证

| 项目 | 内容 |
|------|------|
| 核心病机 | 脾气不足，运化失健 |
| 临床表现 | 食少纳呆、腹胀（食后尤甚）、便溏、肢体倦怠、神疲乏力、少气懒言、面色萎黄、形体消瘦或浮肿 |
| 舌象 | **舌质淡白或淡红，舌体胖大，边有齿痕，苔薄白** |
| 脉象 | 缓弱 |
| 治法 | 健脾益气 |
| 代表方 | 四君子汤、参苓白术散 |
| 选穴 | 足三里、太白、中脘、气海 |

### 证型二：脾阳虚证（中焦虚寒）

| 项目 | 内容 |
|------|------|
| 核心病机 | 脾阳衰微，失于温煦，阴寒内生 |
| 临床表现 | 腹胀纳少、腹痛喜温喜按、大便清稀（甚则完谷不化）、畏寒肢冷、面浮肢肿、小便短少、带下清稀量多 |
| 舌象 | **舌质淡胖，苔白滑** |
| 脉象 | 沉迟无力 |
| 治法 | 温中散寒，健脾助运 |
| 代表方 | 理中汤、附子理中丸 |
| 选穴 | 神阙（灸）、关元、足三里、阴陵泉、太白 |

### 证型三：脾虚湿盛证

| 项目 | 内容 |
|------|------|
| 核心病机 | 脾气虚弱，水湿不运，湿邪内停 |
| 临床表现 | 脘腹痞闷、纳呆、口淡不渴、头身困重、大便溏泄（黏滞不爽）、肢体浮肿、小便不利、妇女带下量多色白 |
| 舌象 | **舌淡胖，苔白腻** |
| 脉象 | 濡缓 |
| 治法 | 健脾益气，渗湿利水 |
| 代表方 | 参苓白术散、胃苓汤 |
| 选穴 | 阴陵泉、足三里、三阴交、水分、脾俞 |

### 证型四：心脾两虚证

| 项目 | 内容 |
|------|------|
| 核心病机 | 心血不足，脾气虚弱，心神失养 |
| 临床表现 | 心悸怔忡、失眠多梦、健忘、食少腹胀、便溏、倦怠乏力、面色萎黄、月经量少色淡或崩漏 |
| 舌象 | **舌质淡嫩，苔薄白** |
| 脉象 | 细弱 |
| 治法 | 补益心脾，养血安神 |
| 代表方 | 归脾汤 |
| 选穴 | 心俞、脾俞、神门、三阴交、足三里 |

### 证型五：脾不统血证

| 项目 | 内容 |
|------|------|
| 核心病机 | 脾气虚弱，统血无权，血溢脉外 |
| 临床表现 | 便血、尿血、肌衄（皮下出血）、鼻衄、齿衄，妇女月经过多或崩漏，伴食少便溏、神疲乏力、气短懒言 |
| 舌象 | **舌质淡，苔白** |
| 脉象 | 细弱 |
| 治法 | 健脾益气，摄血止血 |
| 代表方 | 归脾汤合黄土汤 |
| 选穴 | 隐白（灸）、太白、足三里、气海、脾俞 |

### 证型六：寒湿困脾证

| 项目 | 内容 |
|------|------|
| 核心病机 | 寒湿内侵，中阳受困 |
| 临床表现 | 脘腹痞闷胀痛、食少便溏、恶心欲吐、口淡不渴、头身困重、面色晦黄、肢体浮肿、小便短少、妇女白带量多 |
| 舌象 | **舌淡胖，苔白腻** |
| 脉象 | 濡缓 |
| 治法 | 温中散寒，化湿醒脾 |
| 代表方 | 胃苓汤、实脾饮 |
| 选穴 | 阴陵泉、足三里、中脘、水分、脾俞、胃俞 |


## 四、舌象特征总结

| 证型 | 舌质 | 舌苔 | 关键鉴别点 |
|------|------|------|------------|
| 脾气虚 | 淡白/淡红，胖大，齿痕 | 薄白 | 舌淡+齿痕+薄白苔 |
| 脾阳虚 | 淡胖 | 白滑 | 舌淡胖+苔白滑（水滑） |
| 脾虚湿盛 | 淡胖 | 白腻 | 舌淡胖+苔白腻 |
| 心脾两虚 | 淡嫩 | 薄白 | 舌淡嫩+苔薄白 |
| 脾不统血 | 淡 | 白 | 舌淡+出血表现 |
| 寒湿困脾 | 淡胖 | 白腻 | 苔白腻+舌淡胖（与脾虚湿盛相似，但起病急、实证为主） |


## 五、规则格式（条件→结论→行动）

### ⚠️ P0级安全规则（孕妇禁忌优先回流）

```
条件：患者为孕妇 + 就诊于脾经相关疾病
→ 结论：三阴交、隐白、血海等穴位存在刺灸禁忌风险
→ 行动：①禁用三阴交（有引发流产风险）；②隐白、血海慎用或禁用强刺激；
       ③推荐使用脾俞、胃俞、足三里（非孕期禁忌穴）替代；④所有操作前必须确认妊娠状态
```

```
条件：患者为孕妇 + 出现水肿/腹胀/便溏
→ 结论：孕期脾虚湿停常见，但不可按常规取穴施治
→ 行动：①禁用三阴交、血海；②选用阴陵泉、足三里、脾俞（避开腹部穴位）；
       ③建议配合饮食调理（山药、薏苡仁粥）；④必要时转诊产科
```

### 脾气虚证规则

```
条件：食少纳呆 + 腹胀（食后加重）+ 便溏 + 倦怠乏力 + 舌淡胖有齿痕 + 苔薄白 + 脉缓弱
→ 结论：脾气虚证
→ 行动：①针刺足三里、太白、中脘、气海，补法；②灸足三里、气海各10-15分钟；
       ③方用四君子汤或参苓白术散；④嘱规律饮食，忌生冷
```

### 脾阳虚证规则

```
条件：腹胀纳少 + 腹痛喜温喜按 + 大便清稀（完谷不化）+ 畏寒肢冷 + 舌淡胖苔白滑 + 脉沉迟无力
→ 结论：脾阳虚证（中焦虚寒）
→ 行动：①重用灸法——神阙隔姜灸、关元、足三里各15-20分钟；②针刺阴陵泉、太白，补法加温针灸；
       ③方用理中汤或附子理中丸；④忌食生冷寒凉，注意腹部保暖
```

### 脾虚湿盛证规则

```
条件：脘腹痞闷 + 纳呆 + 头身困重 + 便溏黏滞 + 肢体浮肿 + 舌淡胖苔白腻 + 脉濡缓
→ 结论：脾虚湿盛证
→ 行动：①针刺阴陵泉、足三里、三阴交、水分，平补平泻；②灸脾俞、足三里各10分钟；
       ③方用参苓白术散合平胃散；④建议适量运动（如快走）助运化湿
```

### 心脾两虚证规则

```
条件：心悸失眠 + 健忘 + 食少腹胀 + 便溏 + 倦怠乏力 + 面色萎黄 + 月经量少色淡 + 舌淡嫩苔薄白 + 脉细弱
→ 结论：心脾两虚证
→ 行动：①针刺心俞、脾俞、神门、三阴交、足三里，补法；②灸心俞、脾俞各10分钟；
       ③方用归脾汤加减；④嘱调畅情志，避免思虑过度
```

### 脾不统血证规则

```
条件：便血/尿血/肌衄/月经过多或崩漏 + 食少便溏 + 神疲乏力 + 舌淡苔白 + 脉细弱
→ 结论：脾不统血证
→ 行动：①重灸隐白（崩漏要穴）15-20分钟；②针刺太白、足三里、气海、脾俞，补法；
       ③方用归脾汤合黄土汤；④若出血量多，需中西医结合急诊处理
```

### 寒湿困脾证规则

```
条件：脘腹痞闷胀痛 + 食少便溏 + 头身困重 + 面色晦黄 + 舌淡胖苔白腻 + 脉濡缓
→ 结论：寒湿困脾证
→ 行动：①针刺阴陵泉、中脘、足三里、水分，平补平泻加温针灸；②灸神阙、脾俞各15分钟；
       ③方用胃苓汤或实脾饮；④忌生冷油腻，宜食温热易消化食物
```

### 水肿（脾虚水泛）规则

```
条件：肢体浮肿（以下肢为甚）+ 脘腹胀满 + 小便短少 + 食少便溏 + 舌淡胖苔白滑 + 脉沉缓
→ 结论：脾虚水泛（阴水）
→ 行动：①针刺阴陵泉、水分、足三里、三阴交，平补平泻；②灸脾俞、肾俞各10-15分钟；
       ③方用实脾饮合五苓散；④限盐饮食，监测体重和尿量
```

### 月经不调（脾虚型）规则

```
条件：月经先期/量多色淡/淋漓不尽 + 食少便溏 + 倦怠乏力 + 舌淡苔白 + 脉细弱
→ 结论：脾虚失统，冲任不固
→ 行动：①灸隐白、太白各10-15分钟；②针刺三阴交、血海、足三里、气海，补法；
       ③方用归脾汤或补中益气汤加减；④经期避免过度劳累
```

### 腹胀（食积/气滞）规则

```
条件：脘腹胀满 + 嗳气食少 + 大便不畅或溏 + 舌淡红苔白 + 脉缓
→ 结论：脾失健运，气机不畅
→ 行动：①针刺公孙、太白、足三里、中脘，平补平泻；②配内关（八脉交会配穴）理气消胀；
       ③可加天枢调理肠腑；④嘱少食多餐，忌暴饮暴食
```

### 便溏（慢性泄泻）规则

```
条件：大便溏薄/时溏时泻 + 食少腹胀 + 神疲倦怠 + 舌淡苔白 + 脉细弱
→ 结论：脾虚泄泻
→ 行动：①针刺太白、足三里、天枢、中脘，补法；②灸神阙、脾俞各10-15分钟；
       ③方用参苓白术散；④忌生冷油腻，注意腹部保暖
```


## 六、配穴规则总结

### （一）八脉交会配穴法

```
条件：胃脘痛/心痛/胸膈痞闷 + 呕吐/呃逆
→ 结论：胃心胸病变
→ 行动：公孙（通冲脉）配内关（通阴维脉）——上下配合，理气宽胸、和胃降逆
```

### （二）俞募配穴法

```
条件：各种脾胃虚弱证候
→ 结论：脾病虚证
→ 行动：脾俞（背俞穴）配章门（募穴）——俞募相配，健脾益气
```

### （三）原络配穴法

```
条件：脾胃不和 + 消化不良
→ 结论：脾经与胃经表里同病
→ 行动：太白（脾经原穴）配冲阳（胃经原穴）或公孙（络穴）配丰隆（胃经络穴）
```

### （四）合穴配穴法

```
条件：腹胀 + 小便不利 + 水肿
→ 结论：水湿内停
→ 行动：阴陵泉（脾经合穴·水）配足三里（胃经合穴·土）——培土制水
```

### （五）特定穴组合

| 目的 | 穴位组合 | 机制 |
|------|----------|------|
| 健脾益气 | 太白 + 足三里 + 气海 | 原穴+合穴+补气要穴 |
| 健脾利湿 | 阴陵泉 + 三阴交 + 水分 | 利水三要穴 |
| 统血止血 | 隐白（灸）+ 太白 + 血海 | 井穴统血+原穴健脾+血海调血 |
| 调经养血 | 三阴交 + 血海 + 归来 | 调和冲任、养血调经 |
| 安神助眠 | 三阴交 + 神门 + 心俞 | 健脾养血、宁心安神 |


## 七、临床应用要点

### （一）辨证要点

1. **辨虚实**：脾病多虚，但需辨清有无实邪（寒湿、湿热、食积）
2. **辨寒热**：脾阳虚多寒象（畏寒肢冷、腹痛喜温）；湿热蕴脾多热象（口苦、苔黄腻）
3. **辨气血**：气虚为主还是血虚为主，或气血两虚

### （二）治疗原则

| 原则 | 具体操作 |
|------|----------|
| 虚则补之 | 针刺用补法，重用灸法 |
| 寒则温之 | 温针灸、隔姜灸、艾炷灸 |
| 湿则利之 | 取阴陵泉、水分等利水要穴 |
| 陷下则灸之 | 脾气下陷（脱肛、胃下垂）重灸气海、百会 |

### （三）日常调护

```
条件：脾虚体质 + 日常保健
→ 结论：需要长期调理
→ 行动：①每日按揉足三里、三阴交各3-5分钟；②晨起喝生姜红枣茶；
       ③饮食规律，忌生冷、油腻、甜腻；④适度运动（八段锦、散步）；
       ⑤保持心情舒畅，避免思虑过度
```
