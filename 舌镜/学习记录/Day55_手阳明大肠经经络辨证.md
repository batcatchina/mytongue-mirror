## 一、辨证规则

### 规则55-1：大肠经实热证
- **条件**：舌象（舌红、苔黄燥）+ 经脉症状（循行部位红肿热痛，如齿痛、颈肿、肩前痛）+ 腑证（口干、便秘、腹痛拒按）+ 脉象（滑数）
- **结论**：手阳明大肠经实热证
- **行动**：清热泻火，通腑导滞
- **配穴方案**：
  - 主穴：合谷（LI4）、曲池（LI11）、天枢（ST25）、上巨虚（ST37）
  - 配穴：口干加内庭（ST44）；便秘加支沟（SJ6）；齿痛加颊车（ST6）、下关（ST7）
- **P0禁忌**：⚠️ 严禁灸法（尤其艾条悬灸），忌用温补手法（如烧山火）。忌食辛辣、羊肉、酒类等助热食物。

### 规则55-2：大肠经虚寒证
- **条件**：舌象（舌淡胖、苔白滑）+ 经脉症状（循行部位冷痛、喜温喜按，如肩臂冷痛、肠鸣）+ 腑证（腹痛喜温、腹泻清稀、完谷不化）+ 脉象（沉迟或沉弱）
- **结论**：手阳明大肠经虚寒证
- **行动**：温阳散寒，健脾止泻
- **配穴方案**：
  - 主穴：天枢（ST25）、关元（CV4）、足三里（ST36）、神阙（CV8，隔姜灸）
  - 配穴：腹泻加阴陵泉（SP9）；肩臂冷痛加肩髃（LI15）温针灸；肠鸣加公孙（SP4）
- **P0禁忌**：⚠️ 严禁单纯泻法（如强刺激、放血），忌用寒凉药物（如大黄、芒硝）。忌食生冷、瓜果、冰饮。

### 规则55-3：大肠经湿热证
- **条件**：舌象（舌红、苔黄腻）+ 经脉症状（循行部位沉重、酸胀、灼热，如肩臂重坠、肛门灼热）+ 腑证（里急后重、下痢脓血、或大便黏滞不爽、气味臭秽）+ 脉象（滑数或濡数）
- **结论**：手阳明大肠经湿热证
- **行动**：清热利湿，行气导滞
- **配穴方案**：
  - 主穴：曲池（LI11）、合谷（LI4）、天枢（ST25）、上巨虚（ST37）、阴陵泉（SP9）
  - 配穴：里急后重加中脘（CV12）、气海（CV6）；下痢脓血加血海（SP10）；肛门灼热加承山（BL57）
- **P0禁忌**：⚠️ 忌单纯温补（如灸关元、足三里），忌用收涩止泻药（如罂粟壳、诃子）过早，以免闭门留寇。忌食肥甘厚味、甜腻、海鲜发物。

### 规则55-4：大肠经气滞证（经络痹阻）
- **条件**：舌象（舌暗或有瘀点，苔薄白或薄黄）+ 经脉症状（循行部位胀痛、窜痛、活动不利，如肩臂酸痛、食指麻木）+ 腑证（腹胀、嗳气、便秘或便后不爽）+ 脉象（弦或涩）
- **结论**：手阳明大肠经气滞证（经络痹阻）
- **行动**：行气活血，通络止痛
- **配穴方案**：
  - 主穴：合谷（LI4）、曲池（LI11）、肩髃（LI15）、手三里（LI10）
  - 配穴：肩臂痛加肩贞（SI9）；食指麻木加八邪（EX-UE9）；腹胀加太冲（LR3）、支沟（SJ6）
- **P0禁忌**：⚠️ 忌单纯补法（如灸气海、关元），忌用滋腻碍气之品（如熟地、阿胶）。忌久坐不动。

### 规则55-5：大肠经与肺经表里同病证
- **条件**：舌象（舌尖红、苔薄黄或白）+ 经脉症状（大肠经与肺经循行部位均有不适，如肩臂痛伴咳嗽、咽喉痛）+ 腑证（便秘或腹泻，伴咳喘、鼻塞）+ 脉象（浮数或浮紧）
- **结论**：手阳明大肠经与手太阴肺经表里同病证
- **行动**：表里双解，宣肺通腑
- **配穴方案**：
  - 主穴：合谷（LI4）、列缺（LU7）、曲池（LI11）、尺泽（LU5）
  - 配穴：咳喘加肺俞（BL13）；鼻塞加迎香（LI20）；便秘加天枢（ST25）
- **P0禁忌**：⚠️ 忌单纯治肺或治肠，需表里同治。忌用峻下药（如大黄、芒硝）导致肺气更虚。忌用敛肺止咳药过早（如五味子、诃子）以防闭邪。

## 二、⚠️ P0禁忌

1. **实热证与湿热证**：严禁使用灸法（尤其是艾条悬灸、温针灸）及温补手法（烧山火、补法）。忌食辛辣、酒、羊肉、海鲜等发物。
2. **虚寒证**：严禁使用强刺激泻法（如放血、重提插）、寒凉药物（大黄、芒硝、黄连）。忌食生冷、瓜果、冰镇饮料。
3. **湿热证**：严禁过早使用收涩止泻药（罂粟壳、诃子、五味子），以免闭门留寇。忌单纯温补。
4. **气滞证**：严禁单纯补法（灸关元、气海），忌用滋腻碍气药物（熟地、阿胶、黄精）。忌久坐不动。
5. **表里同病证**：严禁单纯治肺或治肠，需表里同治。忌用峻下药导致肺气更虚，忌用敛肺药过早导致闭邪。

## 三、⚠️ 孕妇禁忌总汇

| 证型 | 禁用穴位 | 禁用操作 | 禁用药物/食物 |
| :--- | :--- | :--- | :--- |
| **所有证型** | **合谷 (LI4)**、**三阴交 (SP6)**、**肩井 (GB21)**、**昆仑 (BL60)**、至阴 (BL67) | 强刺激、电针、放血、灸法（尤其腹部、腰骶部穴位） | 大黄、芒硝、巴豆、麝香、水蛭、虻虫、牵牛子、甘遂、大戟、芫花、商陆、附子、乌头、干姜、肉桂、桃仁、红花、牛膝、乳香、没药、五灵脂、王不留行、穿山甲、蜈蚣、全蝎 |
| **实热证** | 同"所有证型" | 严禁泻法、放血 | 同"所有证型" |
| **虚寒证** | 同"所有证型" | 慎用灸法（腹部、腰骶部禁用），可考虑温和灸四肢远端穴位（如足三里） | 慎用附子、干姜、肉桂等大热之品 |
| **湿热证** | 同"所有证型" | 严禁泻法、放血 | 同"所有证型" |
| **气滞证** | 同"所有证型" | 慎用强刺激行气手法 | 慎用破气行气之品（如枳实、厚朴、青皮） |
| **表里同病证** | 同"所有证型" | 严禁强刺激、放血 | 同"所有证型" |

**特别说明**：孕妇禁用穴位中，**合谷 (LI4)** 为手阳明大肠经原穴，具有极强的行气活血、催产作用，为孕期绝对禁忌。所有涉及腹部（如天枢 ST25）、腰骶部（如八髎）的穴位，孕期均应避免针刺或重灸。
