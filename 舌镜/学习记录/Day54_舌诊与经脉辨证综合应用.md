## 一、综合辨证规则

### 规则54-1：阳明经脉实热证
- **条件**：舌质红+苔黄燥/黄腻+胃经/大肠经灼热胀痛+右关滑数
- **结论**：阳明经热，湿热壅滞经脉
- **行动**：清热泻火通经 → 曲池+合谷+内庭+足三里+天枢
- **P0禁忌**：⚠️忌温灸/艾灸/热敷；忌辛辣羊肉酒类

### 规则54-2：太阴经脉虚寒证
- **条件**：舌淡胖+齿痕+苔白滑+脾经/肾经冷痛喜温+左关沉弱/双尺沉弱
- **结论**：经脉虚寒，脾肾阳气不足
- **行动**：温经散寒补阳 → 关元+命门+足三里+脾俞+肾俞
- **P0禁忌**：⚠️忌黄连/黄芩等寒凉药；忌冰敷；孕妇禁针下腹

### 规则54-3：肝心经脉血瘀证
- **条件**：舌紫暗+瘀点/瘀斑+舌下络脉怒张+肝经/心经刺痛固定+左关弦涩
- **结论**：经脉血瘀，气滞或寒凝
- **行动**：活血化瘀通络 → 血海+膈俞+太冲+内关+阿是穴
- **P0禁忌**：⚠️忌止血/收敛药；孕妇禁活血化瘀药

### 规则54-4：肝肾经脉阴虚证
- **条件**：舌红+少苔/无苔/裂纹+肝经/肾经麻木灼热+左尺细数
- **结论**：经脉阴虚，肝肾失养
- **行动**：滋阴润燥柔筋 → 太溪+三阴交+复溜+神门+照海
- **P0禁忌**：⚠️忌附子/肉桂等温燥药；忌艾灸；孕妇禁滋阴降火

### 规则54-5：太阴经脉湿阻证
- **条件**：舌淡+苔白腻/白厚+脾经/膀胱经沉重肿胀+双关滑濡
- **结论**：湿困脾阳，经脉壅滞
- **行动**：健脾祛湿通利 → 阴陵泉+丰隆+脾俞+足三里+中脘
- **P0禁忌**：⚠️忌熟地/阿胶等滋腻药；忌甜食肥肉；孕妇慎用

### 规则54-6：肝经热极生风证
- **条件**：舌红绛+苔少/剥脱+肝经/心包经抽搐痉挛+左关弦数
- **结论**：热入营血，肝风内动
- **行动**：清热凉血息风 → 太冲+风池+大椎+合谷+委中
- **P0禁忌**：⚠️忌温补升阳药；忌情绪激动；孕妇禁针

### 规则54-7：脾胃经脉气血两虚证
- **条件**：舌淡白+苔薄白+脾经/胃经痿软无力+右关虚弱
- **结论**：气血不足，经脉失充
- **行动**：补益气血荣脉 → 足三里+气海+血海+中脘+脾俞
- **P0禁忌**：⚠️忌大黄/枳实等破气药；忌过度劳累；孕妇慎用

### 规则54-8：胆肝经脉湿热瘀阻证
- **条件**：舌红+苔黄腻+胆经/肝经红肿热痛+口苦胁痛+左关弦滑数
- **结论**：肝胆湿热，经脉瘀滞
- **行动**：清热利湿疏肝 → 阳陵泉+太冲+丘墟+胆俞+肝俞
- **P0禁忌**：⚠️忌温补滋腻药；忌饮酒油腻；孕妇禁针

## 二、⚠️ P0综合禁忌

### ⚠️ P0-54-1：热证禁忌
- 阳明经热：禁艾灸/热敷/温灸
- 热极生风：禁温补/升阳/发物

### ⚠️ P0-54-2：寒证禁忌
- 虚寒证：禁黄连/黄芩等寒凉药
- 孕妇：禁针下腹/腰骶穴位

### ⚠️ P0-54-3：瘀证禁忌
- 血瘀证：禁止血/收敛药
- 孕妇：禁活血化瘀药（川芎/红花/桃仁）

### ⚠️ P0-54-4：虚证禁忌
- 气血两虚：禁破气/泻下药
- 阴虚证：禁温燥/艾灸

---

## 三、⚠️ 孕妇禁忌总汇

| 证型 | 禁用 | 原因 |
|------|------|------|
| 实热证 | 艾灸/热敷/清热药过量 | 伤津动血 |
| 虚寒证 | 下腹/腰骶针刺 | 刺激子宫 |
| 血瘀证 | 川芎/红花/桃仁/丹参 | 活血动胎 |
| 阴虚证 | 附子/肉桂/知母/黄柏 | 寒热伤胎 |
| 湿阻证 | 峻下逐水/利水药过量 | 扰动胎气 |
| 热极生风 | 针刺（尤其是头颈部） | 刺激/疼痛 |

## 四、舌镜应用要点

1. **三联辨证**：舌象+经脉症状+脉象，缺一不可
2. **优先级**：舌象>经脉症状>脉象（舌镜主要靠舌象）
3. **安全第一**：有孕妇禁忌之一律⚠️标注
4. **行动具体**：配穴5-7个，涵盖主穴+配穴+辨证穴
