## 一、经脉循行与病候概要

### 经脉循行
**起于**：食指桡侧端（商阳）→ 沿食指桡侧缘 → 第1、2掌骨间（合谷）→ 腕部阳溪 → 前臂桡侧 → 肘外侧（曲池）→ 上臂外侧前缘 → 肩髃 → 巨骨 → 大椎 → 缺盆 → 入胸络肺 → 下膈属大肠

**支脉**：缺盆 → 颈侧 → 颊 → 下齿龈 → 环唇 → 交人中 → 对侧鼻翼旁（迎香）

### 病候概要
- **经病**：齿痛、颈肿、喉痹、目黄、口干、鼻衄、肩前臂痛、食指不用
- **腑病**：腹痛、肠鸣、泄泻、便秘、痢疾
- **表里证**：发热、恶寒、咳嗽、气喘

| 穴位 | 定位 | 功效 | 主治 |
|:---|:---|:---|:---|
| **商阳**（井穴） | 食指桡侧指甲角旁0.1寸 | 清热开窍、利咽 | 热病、昏迷、咽喉肿痛 |
| **二间**（荥穴） | 第2掌指关节桡侧前凹陷 | 清热消肿 | 齿痛、目痛、咽喉肿 |

| **合谷**（原穴） | 第1、2掌骨间中点 | 疏风解表、通络止痛 | 头痛、齿痛、口眼歪斜、发热 |

| **迎香** | 鼻翼外缘中点旁鼻唇沟 | 通鼻窍、散风热 | 鼻塞、鼻衄、面瘫 |

## 三、大肠实证辨证

### 1. 大肠湿热
- **主症**：腹痛、里急后重、下痢脓血、肛门灼热
- **舌象**：舌红、苔黄腻
- **脉象**：滑数
- **治法**：清热利湿、行气导滞

### 2. 肠燥津亏
- **主症**：大便干结、数日一行、口干咽燥
- **舌象**：舌红少津、苔黄燥
- **脉象**：细数
- **治法**：润肠通便、增液行舟

### 3. 气滞腑气不降
- **主症**：腹胀痛、嗳气、便秘、矢气频
- **舌象**：舌暗红、苔薄白
- **脉象**：弦
- **治法**：行气导滞、通腑降气

### 4. 寒实内结
- **主症**：腹痛拒按、便秘、手足不温
- **舌象**：舌淡暗、苔白滑
- **脉象**：沉紧
- **治法**：温里散寒、通便

---

## 四、大肠虚证辨证

### 1. 气虚便秘
- **主症**：虽有便意但排便无力、神疲乏力
- **舌象**：舌淡胖、边有齿痕、苔薄白
- **脉象**：弱
- **治法**：补气润肠

### 2. 阳虚寒凝
- **主症**：大便艰涩、腹中冷痛、畏寒肢冷
- **舌象**：舌淡、苔白滑
- **脉象**：沉迟
- **治法**：温阳通便

### 3. 血虚肠燥
- **主症**：大便干结、面色无华、头晕心悸
- **舌象**：舌淡、苔薄白
- **脉象**：细涩
- **治法**：养血润燥

---

## 五、表里不合

### 1. 肺热移大肠
- **主症**：咳嗽、痰黄、发热、腹泻或便秘
- **舌象**：舌红、苔黄
- **脉象**：数
- **治法**：清肺泻热、通腑

### 2. 肺气不降
- **主症**：胸闷、咳嗽、便秘
- **舌象**：舌淡红、苔薄白
- **脉象**：弦
- **治法**：宣肺降气、通便

---

## 六、经脉辨证

### 1. 大肠经风寒束表
- **主症**：恶寒发热、无汗、头痛、鼻塞、肩臂痛
- **舌象**：舌淡红、苔薄白
- **脉象**：浮紧
- **治法**：疏风散寒、通络

### 2. 大肠经风热犯肺
- **主症**：发热、微恶寒、咽痛、鼻衄、齿痛
- **舌象**：舌尖红、苔薄黄
- **脉象**：浮数
- **治法**：疏风清热、利咽

## 七、舌象特征与脉象要点

### 舌象特征

| 证型 | 舌质 | 舌苔 |
|:---|:---|:---|
| 大肠湿热 | 红 | 黄腻 |
| 肠燥津亏 | 红少津 | 黄燥 |
| 寒实内结 | 淡暗 | 白滑 |
| 气虚便秘 | 淡胖齿痕 | 薄白 |
| 阳虚寒凝 | 淡 | 白滑 |
| 血虚肠燥 | 淡 | 薄白 |
| 风寒束表 | 淡红 | 薄白 |
| 风热犯肺 | 尖红 | 薄黄 |

### 脉象要点
- **实证**：滑、数、弦、紧
- **虚证**：弱、细、迟、涩
- **表证**：浮
- **里证**：沉
