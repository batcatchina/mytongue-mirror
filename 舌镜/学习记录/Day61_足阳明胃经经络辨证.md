## 一、辨证规则

### 规则61-1：胃热证（胃火炽盛）
- **条件**：舌红，苔黄厚或黄燥 + 胃经循行部位（牙龈肿痛、口臭、鼻衄） + 消谷善饥、口渴喜冷饮、大便秘结 + 脉滑数
- **结论**：胃热证
- **行动**：清胃泻火。问诊需确认：是否口渴喜冷饮？大便是否干结？小便是否短黄？有无反酸烧心？
- **配穴方案**：主穴：内庭、厉兑。配穴：合谷、曲池、天枢。
- **P0禁忌**：⚠️ 忌用灸法，忌食辛辣、温补之品。

### 规则61-2：胃寒证（寒邪客胃）
- **条件**：舌淡，苔白滑或白腻 + 胃经循行部位（胃脘冷痛，得热痛减） + 呕吐清水、口淡不渴、大便溏薄 + 脉沉迟或弦紧
- **结论**：胃寒证
- **行动**：温胃散寒。问诊需确认：胃痛是否遇寒加重、得热则舒？是否喜热饮？有无泛吐清水？
- **配穴方案**：主穴：中脘、足三里。配穴：梁门、神阙（灸）。
- **P0禁忌**：⚠️ 忌用寒凉药物及生冷饮食，慎用针刺泻法。

### 规则61-3：胃气上逆证
- **条件**：舌淡红或红，苔薄白或薄黄 + 胃经循行部位（呃逆、嗳气、恶心呕吐） + 脘腹胀满、食入即吐 + 脉弦或滑
- **结论**：胃气上逆证
- **行动**：和胃降逆。问诊需确认：呃逆/嗳气频率？是否与情绪有关？呕吐物性质（食糜/酸水/清水）？
- **配穴方案**：主穴：内关、足三里。配穴：中脘、膻中、公孙。
- **P0禁忌**：⚠️ 实证忌用补法，虚证忌用攻伐。若因食积，忌用收涩。

### 规则61-4：胃阴不足证
- **条件**：舌红少津，苔少或无苔，或有裂纹 + 胃经循行部位（口干唇燥、饥不欲食） + 胃脘隐痛、干呕、大便干结 + 脉细数
- **结论**：胃阴不足证
- **行动**：滋阴养胃。问诊需确认：是否口干咽燥、饮水不解？是否饥而不欲食？大便是否干结如羊屎？
- **配穴方案**：主穴：足三里、三阴交。配穴：内庭、太溪、胃俞。
- **P0禁忌**：⚠️ 忌用温燥、苦寒伤阴之品，忌用灸法。

### 规则61-5：胃阳虚证
- **条件**：舌淡胖，苔白滑 + 胃经循行部位（胃脘冷痛，喜温喜按） + 食少脘痞、畏寒肢冷、神疲乏力 + 脉沉迟无力
- **结论**：胃阳虚证
- **行动**：温中补虚。问诊需确认：是否畏寒怕冷？四肢是否不温？是否喜热食、按之痛减？
- **配穴方案**：主穴：中脘、足三里（灸）。配穴：脾俞、胃俞、关元。
- **P0禁忌**：⚠️ 忌用寒凉攻下，忌食生冷。慎用针刺泻法。

### 规则61-6：食积证（饮食停滞）
- **条件**：舌苔厚腻（白或黄） + 胃经循行部位（脘腹胀满、嗳腐吞酸） + 厌食、呕吐酸腐、大便臭秽或便秘 + 脉滑实
- **结论**：食积证
- **行动**：消食导滞。问诊需确认：是否有暴饮暴食史？腹胀是否拒按？大便是否酸臭或有不消化食物？
- **配穴方案**：主穴：中脘、天枢。配穴：足三里、内关、下脘。
- **P0禁忌**：⚠️ 忌用补益、收涩之品。若积久化热，忌纯用温燥。

## 二、⚠️ P0禁忌

1. **胃热证**：忌用灸法，忌食辛辣、温补之品。
2. **胃寒证**：忌用寒凉药物及生冷饮食，慎用针刺泻法。
3. **胃气上逆证**：实证忌用补法，虚证忌用攻伐。
4. **胃阴不足证**：忌用温燥、苦寒伤阴之品，忌用灸法。
5. **胃阳虚证**：忌用寒凉攻下，忌食生冷。慎用针刺泻法。
6. **食积证**：忌用补益、收涩之品。

## 三、⚠️ 孕妇禁忌总汇

| 证型 | 禁用穴位 | 禁忌治法 | 备注 |
| :--- | :--- | :--- | :--- |
| **胃热证** | 合谷、三阴交、肩井、昆仑、至阴 | 强刺激泻法、放血疗法 | 清胃泻火药需慎用 |
| **胃寒证** | 合谷、三阴交、肩井、昆仑、至阴 | 腹部穴位慎用灸法 | 温胃散寒药需在医师指导下 |
| **胃气上逆证** | 合谷、三阴交、肩井、昆仑、至阴 | 内关、足三里刺激不宜过强 | 降逆药需谨慎 |
| **胃阴不足证** | 合谷、三阴交、肩井、昆仑、至阴 | 滋阴药相对安全但需辨证 | 避免活血化瘀类滋阴药 |
| **胃阳虚证** | 合谷、三阴交、肩井、昆仑、至阴 | 灸法需专业医师操作 | 温补药需辨证使用 |
| **食积证** | 合谷、三阴交、肩井、昆仑、至阴 | 腹部穴位刺激不宜过强 | 山楂有活血作用 |

## 四、知识回流标注

- **虚实鉴别**：实证（胃热、胃寒、食积、气逆）起病急、病程短、疼痛拒按、脉有力；虚证（胃阴不足、胃阳虚）起病缓、病程长、疼痛喜按、脉无力。
- **经络特异性**：胃经循行牙龈、口鼻、上齿、腹胸、下肢前外侧。胃经与脾经相表里，胃病常及脾；胃经循喉咙，胃热可致咽喉肿痛。
- **配穴原则**：本经取穴（足三里、内庭）+ 俞募配穴（胃俞+中脘）+ 原络配穴（冲阳+公孙）+ 远近配穴。
